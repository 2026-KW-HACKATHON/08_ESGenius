# 월계1동 공개자료 스냅샷

- 경계: [서울시 공개 뷰어](https://data.seoul.go.kr/opendata/seoulStay/grid_viewer.html), 2025-06-30. 표시용 Polygon이며 지적 측량 경계가 아닙니다.
- 도로: [© OpenStreetMap contributors](https://www.openstreetmap.org/copyright), 2026-10-05 확보. 월계1동 경계 안의 연결점1,783개·구간1,886개. 고속도로·통행금지 제외, 명시적 보행 일방통행 반영.
- 가로등: [서울 OA-22205](https://data.seoul.go.kr/dataList/OA-22205/F/1/datasetView.do), 파일 등록일2023-12-22. 원자료19,316개 중 경계내16개. 현재 작동 여부·모든 골목 보안등의 전수 목록이 아닙니다.

wolgye1.dataset.json은 확보한 원자료에서 경계 필터와 스키마 변환을 수행한 결과입니다. Java 코드나 SDK 없이 그대로 반입할 수 있습니다. OSM 원자료의 ODbL 이용조건과 출처 표시를 유지하세요. 서울 자료 이용조건은 해당 상세 페이지를 따릅니다.

source.type=OPEN_MAP은 공개 지도이고 현장 조사가 아닙니다. observedAt은 기존 API 필드명이며 dateMeaning에 실제 의미를 명시했습니다. OSM은 원본 갱신 시각, 가로등은 파일 등록일입니다. **현장 관측 시각이 아닙니다.** recheckAt을 이미 지난 시각으로 두고 시설 작동·밝기·접근성을 UNKNOWN으로 유지했습니다. 확보하지 못한 시설이나 현장 상태를 생성하지 않습니다.

기본 .env.example은 DEMO_MODE=false입니다. `npm run data:load`로 실제 스냅샷을 반입하고, 별도 시연이 필요할 때만 DEMO_MODE=true와 별도 DB를 사용합니다. demo.dataset.json과 테스트의 합성 좌표는 테스트·설명용으로만 사용합니다.

보안등 보존본은 [MJU FENCE 원자료 저장소](https://github.com/MJU-Capstone-Design/FENCE_data_analysis)에서 확보했습니다. 원본 경로와 고정 커밋은 wolgye-archived-lights.json에 기록했습니다. 빈 위·경도를 임의 보간하지 않고 지번이 명시된 365개 주소 그룹을 카카오 주소 검색의 법정동·본번·부번·산 여부와 정확히 대조했습니다. 경계 안에서 일치한 290개 주소만 추가했습니다. 중복 기록은 묶고, 모호하거나 검색 실패한 항목은 rejected에 남겼습니다. 점선 마커로 표시하며 현재 조명·야간 경로 가중치에서는 제외합니다.

실내 화장실 비상벨은 실제 벨 좌표가 아닌 건물 위치이고, 경찰 연결·야간 접근·현재 작동 여부는 미확인입니다. 야간 경로 가중치와 실외 근접 집계에서 제외합니다. CCTV 역시 경로 비용에 안전 점수를 추가하지 않으며, 경로 25m 내 등록 위치 수만 보여줍니다. 원자료의 주소 표기와 행정동 경계가 다를 수 있어 좌표 기준으로 범위를 필터링했습니다.

가로등 수집은 전수 확인 완료가 아닙니다. 노원 스마트보안등 OA-15972 공개 조회가 비어 있고, 최신 공개 CSV(2026.05.04~05.10) 다운로드 서버가 응답하지 않았습니다. 전국 비상벨 원자료 파일도 403으로 확보하지 못했습니다. 이 자료를 가공하거나 추정한 시설은 추가하지 않았습니다.

### 반입과 재현

- backend에서 npm run data:cctv: 공개 시트 전체 페이지 수집·좌표 병합. 페이지 오프셋이 100행 단위인 점을 반영하고 원본 행 수를 검증합니다.
- npm run data:archive-lights: 저장소에 포함한 보안등 원본 CSV와 출처 기록을 사용합니다. 주소 응답 캐시는 로컬에서 생성하며 서버의 KAKAO_REST_API_KEY 설정이 필요합니다.
- npm run data:safety: 출처별 스냅샷을 기존 도로망에 병합·검증하고 data/safety-sources.json에 입력 해시를 기록합니다.
- npm run data:load: 검증된 파일을 SQLite에 반입합니다. 기존 계정·제보·통제는 보존합니다.
- raw 응답·필터 결과는 data/safety-research, 서비스용 자료는 data/wolgye-*.json에 보관합니다. 수집 캐시는 Git에서 제외하고 재현에 필요한 보안등 원본 CSV·출처 기록과 서비스용 스냅샷을 포함합니다. 지도 API는 limit/offset/nextOffset으로 전체 항목을 내려주며 500개 이후 지형도 누락하지 않습니다.

## 시연 추천 구간

실제 API의 REFERENCE 조건으로 계산한 2026-10-08 결과입니다. 숫자는 이후 공사·자료 변경에 따라 달라질 수 있습니다. 현재 모든 경사와 휠체어 접근성은 미확인입니다.

| 화면 | 구간 | 결과 | 보여줄 기능 |
|---|---|---|---|
| 거동 불편 | 장월교 인근 보행길 → 석계역 인근 보행길 | 최단 849m·15분·계단 1구간 → 우회 1,407m·24분·계단 0구간 | 최단거리/거동 불편 탭 비교, 558m 우회, 계단 지도 상세 |
| 안심귀갓길 | 석계역 서쪽 보행길 → 광운대역 남쪽 보행길 | 1,159m·20분, 25m 내 가로등 9곳·CCTV 18곳 | 남색 카드·노란 경로·시설 상세·반딧불이 미리보기 |
| 휠체어 | 장월교 인근 보행길 → 석계역 인근 보행길 | 참고 경로 1,407m·24분, 계단 0구간 | 분홍 카드, 통행 미확인 1,407m 표시, 확인된 구간만 찾기 결과 비교 |

안심귀갓길 구간은 공개 좌표 후보 구간들을 비교해 등록 가로등 수와 CCTV 수가 함께 높은 구간을 골랐습니다. 실제 치안이나 밝기 최적성을 보장하지 않습니다. 이 구간은 자료상 최단길과 야간 경로가 같으므로 가짜 우회를 추가하지 않습니다. 휠체어 경로도 턱 없음·넓은 보도·승강기 경유를 확인한 것으로 표시하지 않습니다.

앱 길찾기 → 시연 추천 경로 보기에서 선택하거나 /?showcase=comfort, /?showcase=night, /?showcase=wheelchair로 엽니다. 경로 미리보기를 누르면 GPS 권한 없이 지도 선형을 따라 이동합니다.

## 2026-10-08 공사 자료 갱신·추가

- [도로굴착 공사 현황 OA-22901](https://data.seoul.go.kr/dataList/OA-22901/S/1/datasetView.do)을 다시 수집했습니다. 474행을 224개 기록(허가번호 209개)으로 정리했고, 등록 기간 안의 기록은 12개입니다. 정확히 대조한 월계1동 주소 기준점은 월계동 66-5와 298의 2곳입니다.
- [건설알림이 OA-1222](https://data.seoul.go.kr/dataList/OA-1222/A/1/datasetView.do)에서 월계·광운·석계·영축 사업을 조회해 중복을 제거한 11개 중 경계 안의 7개를 보관했습니다. 4개는 경계 밖으로 제외했습니다. 이 검색으로 월계1동의 모든 공사를 확보했다는 뜻은 아닙니다.
- 새 자료 중 현재 등록 기간인 사업은 **광운대역~월계로간 도로개설공사(1차)**(2025-11-03–2026-12-10)와 **영축산 산림복합체험센터 신축공사**(2026-04-01–2027-01-25)입니다. 공사별 건설알림이 상세 페이지의 기간을 오래된 공개 API 기간보다 우선했습니다. 나머지 5개는 과거 기간입니다.
- 현재 지도에는 기존 주소 기준점 2곳과 사업 대표 위치 2곳, 총 4곳을 표시합니다. 추가 사업은 `PROJECT_POINT`, `routingEligible:false`로 보관합니다. 사업 대표 좌표와 실제 보행 통제선은 다르므로 새 좌표를 자동 통행금지 구간으로 만들지 않습니다.
- 재수집: backend에서 `npm run data:constructions`와 `npm run data:construction-projects`. 후자는 `data/wolgye-construction-projects.json`에 출처, 조회별 SHA256, 상세 페이지 기간 근거와 제외 내역을 기록합니다. 기존 도로굴착 자료가 48시간을 넘으면 주소 기준 자동 회피를 적용하지 않습니다.

### 공사 우회 시연

앱의 `/?showcase=construction`은 **월계동 298 남쪽 보행길 → 북쪽 보행길**입니다. 실제 API의 WALK/FAST/REFERENCE 조건으로 공사 주소 주변을 제외한 최단 경로는 **159m·159초(화면 3분)**, 공사를 고려하지 않은 비교 경로는 **86m**여서 **73m·73초** 추가됩니다. 출발·도착은 보행망 연결점에 일치합니다.

등록 공사 주소 반경 25m에 닿는 도로 구간을 예방적으로 제외한 참고 경로입니다. 실제 공사 범위·현장 통행 가능성을 조사한 경로는 아닙니다. 사업 대표 위치 2곳은 지도 안내에만 사용합니다. 검증 당시 API 응답 원본은 로컬에서 별도로 보관하며 저장소에는 포함하지 않습니다.
