## 개발 실행

Node.js 24가 필요합니다. 루트에서 별도 터미널 두 개로 실행합니다.

```powershell
cd backend
npm ci
npm run setup
npm run mobile
```

```powershell
cd mobile
npm ci
Copy-Item .env.example .env.local
npm run dev
```

PC에서 http://127.0.0.1:5173 접속. Vite가 `/api`를 4101 백엔드로 전달합니다. `VITE_API_URL`은 비워둡니다. 연결 설정에 옛 서버 주소가 저장된 경우 내 정보 → 지도·서버 연결에서 백엔드 주소를 비우고 저장합니다. 로컬 개발 서버는 외부에 노출하지 않습니다.

## 카카오 실제 지도

1. [카카오 Web API 가이드](https://apis.map.kakao.com/web/guide/)에 따라 개발자 앱과 지도 사용 설정을 준비합니다.
2. 개발 도메인 `http://127.0.0.1:5173`, 배포 도메인 `https://본인도메인`을 등록합니다. localhost로 열면 그 주소도 별도 등록합니다.
3. **JavaScript 키**를 `mobile/.env.local`의 `VITE_KAKAO_JAVASCRIPT_KEY`에 입력하고 Vite를 재시작합니다. 앱의 연결 설정에서도 입력할 수 있습니다.
4. **REST API 키**는 `backend/.env`의 `KAKAO_REST_API_KEY`에만 입력하고 백엔드를 재시작합니다. REST 키가 없으면 장소 검색은 확보한 보행망의 명칭 검색으로 제한됩니다.

키가 없는 경우 연결 안내를 표시합니다. 임의 지도나 가상 시설을 실제 지도 대신 표시하지 않습니다. 배경 지도는 Kakao SDK, 경로는 자체 공개자료 보행망 계산입니다.

## 휴대폰 홈 화면 앱

[HTTPS 배포 안내](../deploy/README.md)로 서버를 올린 후 Android Chrome에서 배포 주소를 엽니다. **내 정보 → 홈 화면에 추가**, 또는 Chrome 메뉴(⋮) → **홈 화면에 추가 → 설치/바로가기 만들기**를 선택합니다. 설치 가능 여부와 메뉴 문구는 브라우저에 따라 다릅니다.

PC의 `127.0.0.1` 주소는 휴대폰에서 사용할 수 없습니다. 휴대폰 GPS와 PWA 설치에는 신뢰할 수 있는 HTTPS 서비스 주소가 필요합니다. 참고: [MDN 설치 가능한 PWA](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable).

manifest는 standalone 모드와 192/512 아이콘을 제공합니다. 서비스워커는 오프라인 안내 페이지만 저장하며 API·지도 타일·위치·로그인·경로 결과를 캐시하지 않습니다. 연결이 끊기거나 화면이 숨겨지면 동행 안내를 멈춥니다. 앱 업데이트는 온라인에서 다시 열면 최신 코드를 받습니다.

자료의 날짜와 출처는 [데이터 문서](../backend/docs/wolgye1-data.md)에 있습니다.

## 주민 회원 및 낮·밤 안내 (2026-10-08)

- 내 정보 → 로그인하기 → 회원가입. 닉네임, 이메일, 비밀번호(10~128자), 생활권을 받습니다. 생활권은 자기 선택이며 거주지 인증이 아닙니다.
- 현재 개발 서버(JWT 공급자 미설정)는 SQLite 주민 계정을 사용합니다. 가입 후 로그인하면 저장/제보의 사용자 권한을 사용할 수 있습니다. 비밀번호는 무작위 salt와 scrypt로 저장하고 세션 토큰은 서버에 SHA-256 해시로 보관합니다. 프런트 토큰은 메모리에만 유지되며 새로고침하면 다시 로그인합니다. 세션은 12시간 후 만료하며 로그아웃하면 폐기됩니다. 이메일 소유 확인·비밀번호 찾기는 로컬 회원 기능에 포함되지 않습니다.
- 외부 인증이 설정된 앱에서는 Supabase 회원가입/로그인을 사용합니다. production 백엔드는 기존 JWT 요구사항을 유지하고 로컬 회원 엔드포인트를 노출하지 않습니다. 이메일 확인과 메일 발송은 Supabase 프로젝트 설정이 필요합니다.
- 일반 화면은 일몰~일출에만 노란색/반딧불이 안내를 사용합니다. 낮 안내는 파란색/고양이입니다. 시연 모드의 야간 선택은 시연 시간을 바꾸는 기능입니다.
- 야간 경로 비용은 조명, 확인된 보행 폭, 구간에 연결된 작동 가로등/안심벨을 고려합니다. 폭 2m 미만에 회피 가중치, 폭 미확인에 추가 비용을 적용하고 기존 우회 비율 제한을 유지합니다. 실제 안전을 보장하거나 최단 경로보다 무조건 안전하다는 의미는 아닙니다.
- 시연 모드에는 가로등 4개·안심벨 2개를 표시합니다. 실제 데이터와 분리된 가상 설정입니다.
- 검증: 백엔드 테스트 44개, 모바일 테스트 14개. 계정 권한/위조 세션/만료/로그아웃, 좁은 골목 회피, 고장·오래된 시설의 가중치 제외를 검증했습니다. 가입 폼과 낮/밤 화면은 브라우저에서 확인했습니다.
- 참고 구현 문서: [Node.js crypto](https://nodejs.org/api/crypto.html), [Supabase signUp](https://supabase.com/docs/reference/javascript/auth-signup).

## 경로 연결·조건 수정 (2026-10-08 후속)

가장 가까운 연결점이 끊어진 보행 구간인 경우를 수정했습니다. 장소를 고르면 연결점 수동 선택 없이, 서로 이어지는 도로의 진입점으로 계획합니다. 장소와 도로의 이격거리와 안내에 포함되지 않는 진입 구간을 표시합니다.

최단거리는 FAST를 명시적으로 요청하고 이전 이동 조건을 초기화합니다. 거동 불편은 등록 계단·알려진 급경사를 제외하며 경사 미확인 거리를 표시합니다. 안심귀갓길은 등록 조명·안심벨 근접과 확인된 보행 폭을 고려합니다. 확보한 자료에 차이가 없으면 조건별 경로가 같을 수 있습니다.

현재 GPS 기반 안내 및 위치를 재현하는 경로 미리보기에서 실제 선형의 회전 방향·남은 거리·예상 시간을 표시합니다. 경로 이탈 시 현재 위치에서 다시 찾기를 제공합니다. 회전 지시는 경로 도형 기반이며 도로명·횡단보도 신호·음성 안내는 제공하지 않습니다.

## 지도 시설·시연 추천 경로 (2026-10-08)

지도 레이어에서 가로등·보안등, CCTV, 안심벨, 계단, 언덕, 엘리베이터, 공사를 선택할 수 있습니다. 마커 묶음을 누르면 개별 시설로 들어갑니다. 과거 보안등 주소는 점선이며 현재 시설 좌표와 구분합니다. 경로 화면은 주변 80m 내 관련 시설을 표시하며 전체 목록은 지도 상단 버튼에서 엽니다.

길찾기 → 시연 추천 경로 보기에서 거동 불편·안심귀갓길·휠체어 구간을 엽니다. 바로가기: /?showcase=comfort, /?showcase=night, /?showcase=wheelchair. 세 구간은 현재 API로 계산한 실제 도로 참고 경로이며 /?demo=1, /?film=1의 고정 시연 경로와 별개입니다. 시설 출처·정확한 조건·촬영 순서는 ../backend/docs/wolgye1-data.md에 기록했습니다.
