# 월계동 실제 공사 자료

수집 파일: `wolgye-construction-notices.json` (2026-10-07 KST 최초 수집).

- 제공: 서울특별시 도로관리과, [도로굴착 공사 현황 OA-22901](https://data.seoul.go.kr/dataList/OA-22901/S/1/datasetView.do).
- 이용조건: 공공누리 제1유형, 서울특별시 출처표시. 원자료는 일 단위 갱신이며 앱 수집본은 별도 스냅샷이다.
- 검색: Sheet 공개 조회에서 동에 `월계`를 검색한 뒤 노원구/월계동을 정확히 일치시킨다. 1,000행 제한보다 결과 총수가 많거나 응답이 잘리면 기존 파일을 보존하고 실패한다.
- 최초 결과: 475행. 동일 허가·공사명·기간·행정상태의 도로/포장 중복을 합쳐 225개 이력(서로 다른 허가번호 210개). 기간이 역전된 2020년 자료 1행은 제외하고 `collection.rejected`에 기록했다. 기간·상태가 다른 동일 허가의 이력은 지우지 않는다.
- 2026-10-07 기준 등록기간 내 13건. 이 숫자는 현장에서 실제 작업 중임을 확인한 건수가 아니다. 이후 API는 한국 날짜로 기간 구분을 재계산한다.
- 현재 기간 내 3건은 공사명에 명시된 정확한 지번만 Kakao 주소 API로 조회했다. 이 중 2개 주소 기준점이 확보한 월계1동 경계 안, 1개는 밖이다. 다구간 공사의 대표 지번은 전체 공사 범위를 뜻하지 않는다. 주소가 없는 공사는 좌표를 추정하지 않는다.
- 신청자·전화번호는 수집본에 저장하지 않는다. 공사명은 원자료 문구를 유지한다.

## 다시 수집

`backend` 디렉터리에서 `npm run data:constructions` 실행. 공개자료 수집은 서울시 키 없이 가능하다. 명시 지번의 좌표 변환에는 `backend/.env`의 `KAKAO_REST_API_KEY`를 사용한다. 키가 없거나 변환 실패 시 위치 미확인으로 저장하며 임의 좌표를 넣지 않는다. 성공한 전체 수집본만 임시 파일에서 교체한다.

API: `GET /api/v1/construction-notices`. 수집 후 48시간이 지나면 `stale: true`로 앱에 오래된 자료임을 표시한다. 자동 예약 수집은 설정되지 않았다. 재수집 시 로컬 API는 파일을 다시 읽는다. Docker 배포에는 스냅샷이 포함되므로 갱신 파일로 재배포하거나 `CONSTRUCTION_NOTICES_PATH`에 갱신 파일을 마운트한다.

## 보행 경로와의 관계

공공자료에는 굴착 허가와 기간만 있고 보행 통제선이 없다. 모든 항목의 `pedestrianControl`은 `UNVERIFIED`로 유지한다. 앱은 현재 등록기간 내·수집 후 48시간 이내·월계1동 경계 안 주소 기준점에 대해 반경 25m와 겹치는 보행 구간을 예방적으로 제외해 자동 우회한다. 25m는 서비스의 회피 정책이며 실제 공사 범위 측정값이 아니다. 확인된 통행 금지와 DB에서 분리하며, 임의 통제 사실을 등록하지 않는다.

현재 2개 주소 기준점 주변의 5개 보행 구간이 자동 회피 대상이다. 위치 미확인·경계 밖·오래된 공개자료는 제외 근거로 사용하지 않고 앱에 미반영 건수를 알린다. 우회로가 없으면 공사 구간으로 되돌아가는 경로를 반환하지 않는다. 우회 전 빠른 길과 비교한 추가 거리·시간과 회피한 공사명을 제공한다. 공개자료/기간/유효성 또는 운영 통제 변경 시 경로 버전이 바뀌어 기존 안내를 다시 계산한다.

현장·공식 통제 근거와 보행망 구간을 운영자가 확인하면 기존 `/api/v1/admin/constructions` 절차로 통제를 적용한다. 운영자가 등록한 금지·주의 구간도 자동 회피하며, 확인된 통행 금지는 예정 종료일이 지나도 운영자가 해제할 때까지 유지한다.

월계동은 법정동이고 월계1동과 같지 않다. 다른 동 명칭을 포함하는 광역 사업도 원자료상 월계동에 연결될 수 있어, 상세 위치가 없으면 행정동 미확인으로 표시한다. 건축 현장·실내 공사·미등록 공사까지 포함하는 전체 현장 목록은 아니다.
